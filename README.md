# Straw Bridge Challenge

ストローとテープで橋を作り、耐荷重を競うチームビルディング研修の進行用Webアプリです。

## 機能

- 日本語／英語表示
- チーム名・参加者設定とブラウザ保存
- 備品チェック
- 作戦会議・製作タイマー
- 残り15分／5分のチェックポイント通知
- チームごとの耐荷重記録、自動順位表示
- 全画面表示、キーボードの左右キーによる進行
- PC、タブレット、スマートフォン対応

## ローカル確認

`public` を静的Webサーバーの公開ディレクトリに指定してください。

```powershell
npx serve public
```

## 公開

Cloudflare Pagesでは、フレームワークを `None`、出力ディレクトリを `public` に設定します。
